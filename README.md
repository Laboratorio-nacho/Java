# Programación Orientada a Objetos en Java

Este repositorio contiene una colección de códigos, ejercicios y tareas prácticas desarrolladas en el lenguaje Java para la asignatura de Programación Orientada a Objetos (POO) en la Universidad Santo Tomás (UST).

## Contenido del Repositorio

Los archivos están organizados según la progresión del aprendizaje, abarcando desde la sintaxis básica hasta lógica de algoritmos:

### Fundamentos y Entrada de Datos
*   **Hola.java**: Programa inicial para validar la configuración del entorno mediante la impresión clásica en consola.
*   **constantes.java**: Declaración, uso y restricciones de variables de solo lectura en Java.
*   **operadores.java**: Implementación de operaciones aritméticas, lógicas y de asignación básica.
*   **entrada_de_datos.java**: Captura de información mediante consola utilizando la clase primitiva `Scanner`.
*   **JoptionPane.java**: Captura y despliegue de datos de forma visual utilizando ventanas de diálogo interactivas de la librería `javax.swing`.

### Lógica y Estructuras de Control
*   **mayor.java**: Estructuras condicionales enfocadas en la comparación lógica y toma de decisiones numéricas.
*   **calculadora.java**: Aplicación práctica de control de flujo para ejecutar operaciones matemáticas selectivas.
*   **tareas.java**: Resolución de problemas prácticos y asignaciones entregadas durante las sesiones de clase.

### Algoritmos y Modificadores
*   **estatico.java**: Ejemplos prácticos sobre el uso del modificador `static` en variables y métodos de clase.
*   **burbuja.java**: Implementación manual del algoritmo de ordenamiento de burbuja (Bubble Sort) para el manejo y ordenación de arreglos.

## Tecnologías Utilizadas

*   Java Development Kit (JDK)
*   Paradigma de Programación Orientada a Objetos (POO)

## Propósito

El objetivo de este espacio es almacenar y estructurar el avance práctico de la materia, sirviendo como portafolio de código fuente para evaluaciones, laboratorios y proyectos académicos dentro de la institución.
